Allgemein

Wozu dient diese Webseite?

Die Webseite dient als Benutzeroberfläche für verschiedene bioinformatische Programme, die im Programmierpraktikum implementiert wurden. Die Tools können biologische Sequenzen analysieren, Datenbanken durchsuchen und Proteinstrukturen auswerten.

Welche Arten von Daten werden verarbeitet?

Die Tools arbeiten hauptsächlich mit biologischen Sequenzen und Strukturdateien. Dazu gehören DNA Sequenzen im FASTA Format, Proteinsequenzen aus SwissProt oder UniProt sowie Proteinstrukturen aus der Protein Data Bank (PDB).

Sequence Alignment

Was ist ein Sequenzalignment?

Ein Sequenzalignment vergleicht zwei biologische Sequenzen, um änlichkeiten zwischen ihnen zu identifizieren. Diese Älichkeiten können Hinweise auf gemeinsame evolutionäre Herkunft oder funktionelle Beziehungen liefern.

Wie funktioniert das Alignment Tool?

Das Alignment Tool implementiert klassische Algorithmen der Bioinformatik, insbesondere den Needleman Wunsch Algorithmus für globale Alignments. Die Berechnung basiert auf dynamischer Programmierung und verwendet Substitutionsmatrizen sowie Gap Kosten zur Bewertung der Alignments.

Sekundärstruktur Vorhersage

Was ist GOR?

GOR (Garnier Osguthorpe Robson) ist ein statistisches Verfahren zur Vorhersage der Proteinsekundärstruktur. Aus einer Aminosäuresequenz wird vorhergesagt, ob eine Position zu einer Helix, einem Beta Strang oder einer Coil Struktur gehört.

Datenbank Tools

Was macht das Tool spkeyword?

Dieses Programm durchsucht eine SwissProt Datei nach bestimmten Schlüsselwörtern im Keyword Feld. Für alle passenden Einträge werden die Accession Nummern der Proteine ausgegeben.

Was macht acsearch?

Dieses Tool ruft eine Proteinsequenz anhand ihrer Accession Nummer aus der UniProt Datenbank ab und gibt sie im FASTA Format aus.

Struktur Tools

Was macht makescc?

Dieses Tool berechnet eine Kontaktmatrix aus einer Proteinstruktur. Dazu werden die räumlichen Abstände zwischen Aminosäuren in einer PDB Datei berechnet. Zwei Aminosäuren gelten als Kontakt, wenn ihr Abstand unter einem definierten Schwellenwert liegt.

Sequenz Tools

Was macht genome2aa?

Dieses Tool identifiziert Open Reading Frames (ORFs) in DNA Sequenzen und übersetzt diese anschließend in Aminosäresequenzen.
