Alignment

Pairwise-Alignment mit Gotoh (affine Gaps) oder Needleman-Wunsch (lineare Gaps).

Testdateien: mini/example.pairs + seqlib; optional dayhoff.mat. Bonus Sekundärstruktur: Für Beispiel-Alignment mit SS-Scoring: Pairs example.pairs, Seqlib example.seqlib, Levitt levitt_matrix.txt, SS-Seqlib example.seqlib.ss, SS-Gewicht z. B. 0.3, Ausgabe HTML – dann erscheinen aligned SS (H/E/C) und 3D-Ansicht (JSmol).

Eingabe

Pairs (id1 id2)i
Pairs werden automatisch aus allen eingegebenen / geladenen Sequenzen erzeugt: jede Sequenz gegen jede andere.
Seqlib (id:SEQ)i
Unterstützt FASTA oder id:SEQ. Wenn keine Pairs angegeben sind, können sie automatisch aus den Sequenzen erzeugt werden.
Nur PDB-/UniProt-/SwissProt-IDs eingeben (Seqlib optional)
IDs automatisch in Sequenzen umwandelni
eine ID pro Zeile oder durch Leerzeichen/Komma getrennt
Die gefundenen Sequenzen werden zur Seqlib hinzugefügt. PDB: zuerst aus unserer Datenbank, sonst von RCSB. UniProt/SwissProt: werden bei Bedarf online (rest.uniprot.org) abgerufen. Für bekannte PDB-IDs kann die Sekundärstruktur automatisch aus der Datenbank geladen werden.
Matrix (opt.)i
Levitt-Matrix (opt., nur für Sekundärstruktur)i
Diese Matrix wird zusätzlich zur normalen Substitutionsmatrix verwendet und bewertet H/E/C-Paare für das Sekundärstruktur-Scoring.
SS-Seqlib (opt.)i
SS-Gewichti
Gewichtet den Beitrag der Sekundärstruktur zur Gesamtbewertung. 0 = nur Sequenz (Standard), 0.3 = moderater SS-Einfluss, 1 = starker SS-Einfluss.
