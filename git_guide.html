Hinweis: In dieser Anleitung werden keine Dollarzeichen verwendet, da sie nur den Terminal Prompt anzeigen und nicht Teil der eigentlichen Git Befehle sind.

Wichtige Befehle

git init            Neues Repository im aktuellen Ordner erstellen
git clone URL       Bestehendes Repository lokal kopieren
git pull            Änderungen vom Server holen und integrieren
git fetch           Änderungen vom Server holen ohne Integration
git status          Aktuellen Status anzeigen
git add Datei       Datei für Commit vormerken
git commit          Vorgemerkte Änderungen speichern
git commit -a       Alle Änderungen direkt committen
git push            Lokale Commits hochladen
git diff            Unterschiede anzeigen
git diff HEAD       Unterschiede zur letzten Version
git checkout HEAD   Arbeitsverzeichnis zurücksetzen
git checkout X      Zu Branch, Commit oder Datei wechseln
