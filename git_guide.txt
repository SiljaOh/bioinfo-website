Git Kurz-Anleitung - Gruppe 17

Ueber Git wurden Aenderungen an unserem Code lokal entwickelt, versioniert und anschliessend in das zentrale Repository hochgeladen, sodass alle Gruppenmitglieder darauf zugreifen konnten.
Repository der Gruppe 17: https://gitlab2.cip.ifi.lmu.de/grossla/progprakt-17

Hinweis: In dieser Anleitung werden keine Dollarzeichen verwendet, da sie nur den Terminal-Prompt anzeigen und nicht Teil der eigentlichen Git-Befehle sind.

Wichtige Befehle (Selektion):

git init            -> neues Repository im aktuellen Ordner erstellen
git clone <URL>     -> bestehendes Repository lokal kopieren
git pull            -> Aenderungen vom Server holen und integrieren
git fetch           -> Aenderungen vom Server holen (ohne integrieren)
git status          -> aktuellen Stand des Repositories anzeigen
git add <Datei>     -> Datei fuer den naechsten Commit vormerken
git commit          -> vorgemerkte Aenderungen speichern
git commit -a       -> alle geaenderten Dateien direkt committen
git push            -> lokale Commits zum Server hochladen
git diff            -> Unterschiede zu nicht gespeicherten Aenderungen anzeigen
git diff HEAD       -> Unterschiede zur letzten Version anzeigen
git checkout HEAD   -> Arbeitsverzeichnis auf letzte Version zuruecksetzen
git checkout <X>    -> zu Branch, Commit oder Datei wechseln
