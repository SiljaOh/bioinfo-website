Benchmark: Dynamic Programming vs Recursion

Diese Seite zeigt einen einfachen Laufzeitvergleich zwischen einer rekursiven Implementierung und einer Dynamic Programming Implementierung des Needleman Wunsch Algorithmus.

Einordnung

Ziel dieses Benchmarks war es, den Unterschied in der algorithmischen Effizienz zwischen Rekursion und Dynamic Programming sichtbar zu machen. Beide Methoden berechnen einen optimalen Alignment Score, unterscheiden sich jedoch deutlich in ihrer Laufzeit.

Die rekursive Variante berechnet viele Teilprobleme mehrfach. Dynamic Programming speichert bereits berechnete Zwischenwerte in einer Matrix und vermeidet dadurch redundante Berechnungen. Mit zunehmender Sequenzlänge wird dieser Unterschied immer deutlicher.

Interpretation

Der Benchmark zeigt einen klaren Trend. Bei kurzen Sequenzen sind die Unterschiede noch klein. Ab einer Sequenzlänge von 5 steigt die Laufzeit der rekursiven Methode jedoch sehr stark an, während Dynamic Programming nahezu stabil bleibt.

Besonders deutlich ist dies bei der Sequenzlänge 8. Hier benötigte die rekursive Implementierung 4156 ms, während Dynamic Programming nur 7 ms benötigte. Das verdeutlicht, warum Dynamic Programming in der Praxis deutlich besser für Sequenzalignment geeignet ist.
